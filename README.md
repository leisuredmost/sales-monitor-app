
# Sales Order Monitor

Take home assignment for Harrison Job Application - IT Executive
ChatGPT Assisted

## Features

- Dashboard summary cards
- Paginated sales order listing
- Search by order or customer information
- Site and status filters
- Loading, error, and empty states
- Responsive layout

## Technology

- React
- Vite
- JavaScript
- CSS
- Git and GitHub

## Run locally

Requirements: Node.js and npm.

1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed in the terminal.

## Production build

Run `npm run build`.

## Data source

Uses the supplied fictional, read-only assessment API.
The application sends GET requests and does not modify orders.
